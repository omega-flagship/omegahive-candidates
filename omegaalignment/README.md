## Role procedure

Each mind checks its held request and exact revisions, reads granted evidence once, saves attributable working notes, makes its bounded comparison and returns the declared host receipt before the deadline. Missing records or skills produce an explicit gap. Notes require an actual supported persistence mechanism and task-length TTL; the prompt alone cannot provide working memory.

Drift preserves observed change, evidence and legitimacy as separate judgments. Flourishing preserves affected beings, plural patterns, protected floors, uncertainty and empirical correction. The coordinator retains attributed receipts and dissent and requests independent scrutiny; it cannot grant execution or change the adopted ground.
