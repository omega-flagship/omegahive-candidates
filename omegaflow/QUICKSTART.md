# Using OmegaFlow

OmegaFlow is available in Hive's Flow navigation when the integrated host is deployed. The local preview supplies authoring only.

1. Open **Flow** with a named Hive account and choose a swarm you own, or one your administrator role can manage.
2. Choose **Goal template** for the supported three-step example, or author a flow. Place objects, add relation hubs and edit their ordered roles; transitions describe actions and events. Dragging changes layout, while editing meaning changes the fingerprint.
3. Use the inspector to edit each transition's goal title, detail and optional assignee. All executable goal targets must be the selected swarm. The example's middle goal requires a person's review.
4. **Save revision**, then **Adopt revision** to adopt that exact fingerprint. Saving or arranging a flow does not start it. Save subsequent meaning changes as new revisions and adopt each separately.
5. **Start goal run**. Hive creates the first native goal. Work and review happen through the normal Goals and Inbox surfaces. The flow inspector shows the pinned run and transition statuses; use **Refresh** after work changes.
6. **Cancel** stops unfinished native goals and their children. Removing actor authority blocks further dispatch. **Load stored flow** restores a saved semantic revision and its latest layout sidecar.

Use **Save layout** to retain placement without changing the adopted semantic revision. Export a revision for a local copy. Unsaved drafts live in browser memory and disappear when refreshed or closed; export or save first.

The authoring model can describe more than the first executor accepts. Guarded transitions, loops, joins, subflows, cross-swarm requests, messages and app actions are refused by this version. MeTTa inspection exposes inert, lossless data and structural indexes; it does not run imported expressions or establish native Hyperon inference.

## Authoring templates

Use **Templates** in the canvas toolbar for task review workflows, lead funnels, interaction handoffs, connection maps and the invented garden example. Selection replaces the local draft and is undoable; export it to keep it. Connections support ordered n-ary roles and links about links. The catalogue supplies no live identities or permissions, and selecting a starter never saves, adopts or starts a run. Configure actual host bindings and approvals separately.
