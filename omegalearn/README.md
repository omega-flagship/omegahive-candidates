# OmegaLearn slice 1

Independently importable caller-owned library for LearningEvent intake, immutable
ImprovementPackage proposals, source corrections, local invalidation, checkpoint
recovery and separately evidenced delivery states. Schema:
an owner workspace record (not included).

The caller supplies trusted resolver/authorization callbacks. This library does
not authenticate identities or validate OmegaAtom truth/stamp envelopes itself.
It preserves evidence IDs; use OmegaAtom's validator/host S1 when available.
No callback means no admission/delivery. A callback returning True is not a
production authorization mechanism by itself.

`repair.py` learns a bounded declarative suffix rule from paired examples. MeTTa
rule text remains inert; the example receiver explicitly interprets one supported
rule. Actual loader/MeTTa execution and recipient-space changes are deferred.
`experiment.py` measures unseen synthetic cases and abstention with FULL,
SHAM, SEVERED and exact-example typed-memory controls. No provider/mind runs.
Its diagnostic predicate checks delimiters/quotes, not language semantics.

`program/` is a self-contained read-only contract-0.1 catalogue of components,
experiment and missing host/runtime seams. No mount or registration requested
without platform review. Delivery can use existing artifact/attachment routes,
but this L0 implementation does not call those routes or auto-adopt a package.

Run `python -m pytest omegalearn/tests -q` from workspace root.
PC/NACE adapters and delivery, live cross-swarm reading and host source retraction
are explicitly deferred, per Opus's direction. Pending typed evidence validator,
Lab registration and L1 host delivery/recipient tests remain visible.

Checkpoints are JSON data, not signed/authenticated storage. Save them atomically
in caller-owned storage and bind custody externally. Pure local projections do
not assert cross-module retraction, an adopted ontology or learned model weights.

Continuation: `adapters.py` uses OmegaAtom's actual validator/lineage state and
the existing ProgramContext publication/readback interface. Sixteen L0 checks
and three L1 disposable real-host artifact probes pass; see the owner receipt
`ADAPTER_QUALIFICATION.json`. Proposal publication is qualified; recipient
acknowledgment, attachment and usefulness are not. Source withdrawal needs explicit
trusted local invalidation; no host retract primitive is implemented here.

Latest continuation: `bench_adapter.py` implements an offline prompt-only repair
subject for the existing Bench paired worker. Source/configuration pins, complete
local usage and a bounded-response floor are checked; SHAM computation is metered.
This is public-development plumbing, with no sealed oracle custody or recipient
execution claim. See an owner workspace record (not included) for the
23-check qualification and pending Bench/Platform decisions. Run the explicit
`host_artifact_probes.py` and `attachment_scope_probe.py` files as well as the
standard `test_*.py` files to include the five disposable-host L1 checks.

checks include actual Planner candidate receipt and stale-source refusal. This is
supervised relation extraction, with no sealed capability score or authorization.
